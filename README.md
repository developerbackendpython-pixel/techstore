# TechStore

Sistema de consola en Python para gestionar una tienda de tecnología: inventario, órdenes de compra, clientes VIP y estadísticas de ventas.

Hecho sin POO como ejercicio de estructuras de datos (deque, defaultdict, Counter, sets, namedtuple).

## Cómo ejecutarlo

pip install -r requirements.txt
python main.py
